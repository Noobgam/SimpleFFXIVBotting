# NoobgamSidekick

Fully automated level 1–100 progression for FFXIVMinion, covering MSQ,
class quests, gear upgrades and story duties.

## Features
- Free class quests included for the job levelled.
- Opt-in Duty Finder, or automated dungeon clears using a helper
  (a second character running locally).
- Ravana Extreme farming.

## Requirements
- FFXIVMinion
- LattyLib
- FFXIVLib
- KitanoiFuncs and Kitanoi Dungeon Framework
